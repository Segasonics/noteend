# 📝 NoteEnd

**NoteEnd** is a full-stack note-taking app built with the MERN stack. Users can create, edit, and delete notes with a responsive and modern UI. Authentication and secure token management are included to protect user data.

---

## 🚀 Features

- 🔐 User authentication (access + refresh tokens with cookies)
- 📄 Create, edit, delete personal notes
- 📱 Responsive layout
- ☁️ Deployed with HTTPS support

---

## 🛠️ Tech Stack

**Frontend:**
- React
- Vite
- Axios
- Tailwind CSS
- React Icons

**Backend:**
- Node.js
- Express.js
- MongoDB (Mongoose)
- JSON Web Tokens (JWT)
- Redis (for refresh token storage)
- CORS, cookie-parser
